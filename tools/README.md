# Tools

This directory contains optional helpers and integrations that are not part of the main Utsuwa application, but make self-hosting easier.

## Contents

- [`omnivoice/`](./omnivoice) — OpenAI-compatible FastAPI proxy for the local [OmniVoice](https://github.com/k2-fsa/OmniVoice) text-to-speech model. See the [OmniVoice setup guide](../src/content/docs/guides/omnivoice.md) for installation and usage instructions.
